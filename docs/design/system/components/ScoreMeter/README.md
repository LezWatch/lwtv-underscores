Use to show a show's score out of 100 (`lezshows_the_score`). Pass `score` as a number; values are rounded and clamped to 0–100. Pass `null` to show N/A for an unscored show. The bar is `pink`; the number is Oswald with tabular digits.

The theme defines no score color bands, so the meter uses one brand color. The consumer provides the score value; do not compute it here.
