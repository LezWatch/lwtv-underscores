Use for text, email, search, number, select and textarea input. Pass `id` and `label`. Add `hint` for help text; add `error` to mark the field invalid and show a message that starts with the word "Error".

Inputs stay white in both themes, as on the live site. The focus ring is `pink-deep` on light surfaces and `pink-light` on the dark surface. The consumer provides value handling (`value` and `onChange`, or `defaultValue`).

Do: always give a visible label. Don't: use placeholder text as the label.
