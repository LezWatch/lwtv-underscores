Use for actions. `variant="solid"` (default) is the primary action: `pink` fill, white text, and on hover a white fill with `pink-deep` text. Use `variant="outline"` for secondary actions. Pass `href` to render a link that looks like a button.

The consumer provides the label as children and the click handler.

Do: one solid button per view. Don't: use a button for navigation inside body copy; use a link.
