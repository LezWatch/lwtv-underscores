Use for items in a listing, such as shows, characters and actors. It is square with a flat shadow, as in the theme's loop grids. An optional `title` sits in the purple gradient header with white Oswald text; an optional `image` fills the top.

The consumer provides the title text, the image URL and alt text, and the body as children.

Do: keep the body to short facts and badges. Don't: round the corners or add heavier shadows.
