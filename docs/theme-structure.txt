# LWTV Theme Structure

This document describes the structure and contents of the LezWatch.TV theme. The
main plugin is bundled in this same repository at `/plugins/lwtv-plugin/` and is
documented separately in `docs/plugin-structure.txt`.

## Theme Includes - `/inc/`

Template tags, walkers, widgets, and theme-side JS/CSS.

├── author-box.php - `lwtv_author_box()` content filter appending an author bio box (avatar, name, socials, bio, post count link, favourite shows) to single posts
├── class-wp-bootstrap-4-navwalker.php - Vendored WP Bootstrap Navwalker 4.3.0, class renamed `WP_Bootstrap_Navwalker4`
├── class-wp-bootstrap-5-navwalker.php - Vendored WP Bootstrap Navwalker 5.0.0 (`WP_Bootstrap_Navwalker`) — the walker actually used for the Bootstrap 5 navbar
├── custom-header.php - Registers `custom-header` support (2250x602, flex height) and the head callback that prints header text colour CSS
├── customizer.php - postMessage transport for blogname/blogdescription/header_textcolor; enqueues the Customizer preview JS
├── extras.php - Misc filters: `group-blog`/`hfeed` body classes, pingback link in `wp_head`
├── template-tags.php - Paging/post nav, `lwtv_theme_posted_on()`, entry footer, categorized-blog transient, `lwtv_generate_pagination_buttons()` and page-number helpers
├── walker-comment.php - `LWTV_Walker_Comment`, a fork of core `Walker_Comment` producing the theme's HTML5 comment/pingback markup
├── wp_bootstrap_pagination.php - `wp_bootstrap_pagination()` — Bootstrap `.pagination` nav with range/prev/next for any WP_Query
├── bootstrap/ - VENDORED Bootstrap 5 dist CSS/JS, copied in from `vendor/twbs/bootstrap` by `_build_scripts/copy-composer-assets.sh`. Not hand-edited.
├── css/
│   ├── style-admin.scss - Source for the wp-admin/wp-login skin (login logo, form shadow, dashboard header logo)
│   └── style-admin.css - Compiled output
├── js/
│   ├── a11y.js - Adds `aria-labelledby`/`aria-label` to nav-menu widgets, the social menu, and Gravity Forms widgets
│   ├── bootstrap-color-mode.js - Bootstrap colour-mode toggler: reads/writes `theme` in localStorage, sets `data-bs-theme`, light/dark/auto
│   ├── bootstrap-color-mode.min.js - Build output
│   ├── copy-post-link.js - Swaps the permalink anchor for a copy-to-clipboard button with an aria-live status message
│   ├── customizer.js - Live-preview bindings for site title, description, header text colour
│   ├── customizer.min.js - Build output
│   ├── lwtv-theme-scripts.js - jQuery smooth-scroll for breadcrumb/TOC anchors plus Bootstrap tooltip init
│   ├── navigation.js - `_s` mobile nav toggle with `aria-expanded` handling and keyboard/tab support for dropdown submenus
│   ├── overlay-linkable.js - Makes Bootstrap modals deep-linkable by syncing an `?overlay=` query param on show/hide, auto-opening on load
│   ├── popper.min.js - VENDORED Popper.js core v2.11.8 (+ source map), the positioning engine Bootstrap dropdowns/tooltips need
│   ├── searchbox.js - Opens/closes the header search overlay (`#search`, Esc to close) and focuses the input when the collapse expands
│   ├── skip-link-focus-fix.js - `_s` fix making skip-link targets focusable on hashchange
│   └── yikes-theme-scripts.min.js - BUILD OUTPUT bundling navigation + skip-link-focus-fix + lwtv-theme-scripts + a11y + searchbox + copy-post-link
└── widgets/
    ├── calendar-widget.php - `LWTV_Calendar_Widget` ("LWTV Calendar"): today's air-date calendar card via the plugin's Calendar component
    ├── character-widget.php - `LWTV_Character_Widget` ("LWTV Recent Character"): most recently added character
    ├── filter-bottom-widget.php - `LWTV_Filter_Bottom_Widget`: emits only the closing `.card-body`/`.card` markup wrapping the filter widgets
    ├── filter-top-widget.php - `LWTV_Filter_Top_Widget`: opens the filter `.card` with a title and optional symbolicon
    ├── my-widget.php - `My_Widget`: boilerplate two-textarea example widget, kept as a template
    ├── otd-widget.php - `LWTV_Today_Widget` ("LWTV Today"): character/show/death of the day from the `lwtv/v1` REST API, type selectable
    ├── show-widget.php - `LWTV_Show_Widget` ("LWTV Recent Show"): most recently added show
    └── social-nav-widget.php - `LWTV_Social_Menu_Widget`: renders the `social_menu` location, horizontal or vertical

## Build Scripts - `/_build_scripts/`

├── copy-composer-assets.sh - Composer post-install/post-update hook copying Bootstrap dist CSS/JS (and Popper) from `vendor/` into `inc/bootstrap` (replaces the unmaintained slowprog/composer-copy-file)
├── postbuild.js - Post-webpack step: copies built min JS into `inc/js/`, copies tablesorter into the plugin assets, and concatenates `scss/_header.scss` (with the package.json version substituted for `THEME_VERSION`) onto the built CSS to produce `style.css`
├── structure-docs.js - Regenerates the trees in `docs/plugin-structure.txt` and `docs/theme-structure.txt` from disk, carrying existing descriptions and entry order across; marks new files `TODO: describe` and reports deletions. `npm run docs:structure` / `docs:structure:check`
├── structure-docs.config.js - Config for structure-docs.js: which tree block maps to which directory, what to ignore or pin, and which directories are summarized (`list`) or left prose-only (`opaque`) instead of expanded
├── symbolicons.js - Clones/pulls the private `LezWatch/symbolicons-private` repo (branch from `LWTV_BRANCH`) into `tmp-icons`, then copies `_symbolicons.scss`, `_symbolicons-map.scss` and `symbolicons.json` into the theme
├── versioning.js - Syncs the `$versions[...]` array in `functions.php` with the package.json theme version and the detected Bootstrap / lwtv-blocks versions
├── webpack.config.js - Extends `@wordpress/scripts`: writes `scss/_dynamic.scss`, injects it via sass-loader `additionalData`, and defines the entries `js/yikes-theme-scripts.min`, `js/customizer.min`, `js/bootstrap-color-mode.min`, `css/style`, `css/style-editor`
├── webpackdist/ - Gitignored webpack output staging dir (`css/`, `js/`) that postbuild.js copies from
└── tmp-icons/ - Disposable local clone of the private symbolicons repo, created by symbolicons.js

## Tests - `/tests/`

PHPUnit 11 harness over the plugin's **pure-transform** logic. The bootstrap does
not load WordPress: it defines `ABSPATH`/`DAY_IN_SECONDS`, loads Composer autoload,
shims only pure WP functions (`wp_parse_url`, `__`), then `require_once`s the
classes under test directly. Run with `vendor/bin/phpunit`.

├── bootstrap.php
└── unit/
    ├── CPTs/ - Show/character logic: airdates, character score, longevity, show rating, show tropes, trigger warnings, and the watch-provider helpers (host name, host map, term match, term URL audit, URL health)
    ├── Calendar/ - The calendar Agenda builder
    ├── Components/ - The transient warm-schedule component
    ├── Debugger/ - Issue registry, findings, findings-store TTL, baseline, row formatting, and the show/character/actor/actor-completeness/on-air/BYQ/duplicate/IMDb/queer/log rule sets
    ├── Helpers/ - IMDb URL/ID canonicalisation
    ├── Statistics/ - Overview factsheet, intersection pairs, decade buckets (format/genre/character identity), score and term-count distributions, series trend, star and role podiums, trigger levels, trope category coverage, we-love compare, worth-it grid
    └── This_Year/ - Trends, breakdowns, standouts, shows block, shared builder, character facts, characters on air, dead characters, deaths strip, longest running, formatter year matching

Only pure logic is covered here. Anything that reads WP globals, post meta, or runs
queries is verified against the running site instead — templates, widgets, and JS
are not unit-tested.

## Cron - `/cron/`

Shell scripts for the server crontab. Per `cron/README.md` these live in the repo
as a **backup only** and are not deployed by CI. Each pings a health.ipstenu.com
heartbeat UUID on success or failure.

├── README.md
├── ping.sh - Shared helper that POSTs a success/`/fail` ping for a given UUID
├── debug.sh - `wp lwtv generate debug` (site debugger scan) → UUID `run-debug-checks`
├── hourly.sh - `wp lwtv generate cron hourly` → UUID `due-now-hourly`
├── lists.sh - `wp lwtv generate lists` (rebuild generated list pages) → UUID `generate-lists`
├── ontheten.sh - `wp cron event run --due-now` every ten minutes; the real WP-Cron driver → UUID `due-now-10-min`
├── otd.sh - Flushes the object cache, then `wp lwtv generate otd` → UUID `set-char-and-show-otd`
└── tvmaze.sh - `wp lwtv generate tvmaze` (refresh show data from TVmaze) → UUID `update-tvmaze`
